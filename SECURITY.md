# Security Policy

This repository holds the static site published at https://blog.lesis.lat. It has no server-side code and stores no user data; the newsletter form posts to Kit, page views are measured by Google Analytics, and the clap button talks to applause-button.com.

## Reporting a vulnerability

Write to security@lesis.lat. Please include the affected URL or file, steps to reproduce, and the impact you expect. We answer within five business days and keep you informed until the issue is closed.

Please do not open a public issue for security reports, and do not test against readers of the site.

The machine-readable version of this policy is at https://blog.lesis.lat/.well-known/security.txt.
